# getRate()

Return how often automation runs.

## Parameters

`Automate.getRate()` is a static utility. Call it on the `Automate` class itself, for example:

```python
Automate.getRate()
```

## Returns

`return frameRate`

| Value | Type | Description |
|---|---|---|
| frameRate | `int` | The current rate, in frames per second. |
