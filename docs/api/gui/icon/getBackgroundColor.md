# getBackgroundColor()

Return the icon's background [Color](../color/index.md).  Identical to [getColor()](../common/color/getColor.md)

## Parameters

Once an object `icon` has been created, you can use the following function:

```python
icon.getBackgroundColor()
```

## Returns

`return color`

| Value | Type | Description |
|---|---|---|
| color | `Color` | The current background color. |
