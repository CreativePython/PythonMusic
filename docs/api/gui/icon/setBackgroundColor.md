# setBackgroundColor()

Set the icon's background [Color](../color/index.md).  Identical to [setColor()](../common/color/setColor.md)

## Parameters

Once an object `icon` has been created, you can use the following functions:

```python
icon.setBackgroundColor()
```

```python
icon.setBackgroundColor(color)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `color` | `Color` | `None` | The new background color. If omitted, a color-selection dialog opens. |
