# onAction()

Register a function to call when the slider moves.

## Parameters

Once an object `slider` has been created, you can use the following function:

```python
slider.onAction(action)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `action` | `function` | _required_ | The function to call when the slider moves; it receives one parameter, the new value. |
