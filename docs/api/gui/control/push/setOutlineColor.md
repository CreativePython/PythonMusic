# setOutlineColor()

Set the push button's outline [Color](../../color/index.md).

## Parameters

Once an object `push` has been created, you can use the following functions:

```python
push.setOutlineColor()
```

```python
push.setOutlineColor(color)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `color` | `Color` | `None` | The new outline color. If omitted, a color-selection dialog opens. |
