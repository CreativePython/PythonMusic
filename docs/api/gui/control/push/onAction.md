# onAction()

Register a function to call when the push button is pressed or released.

## Parameters

Once an object `push` has been created, you can use the following function:

```python
push.onAction(action)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `action` | `function` | _required_ | The function to call when the push button is pressed or released; it receives the new value. |
