# setOutlineColor()

Set the toggle's outline [Color](../../color/index.md).

## Parameters

Once an object `toggle` has been created, you can use the following functions:

```python
toggle.setOutlineColor()
```

```python
toggle.setOutlineColor(color)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `color` | `Color` | `None` | The new outline color. If omitted, a color-selection dialog opens. |
