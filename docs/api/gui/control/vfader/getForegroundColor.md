# getForegroundColor()

Return the fader's foreground [Color](../../color/index.md).  Identical to [getColor()](../../common/color/getColor.md)

## Parameters

Once an object `fader` has been created, you can use the following function:

```python
fader.getForegroundColor()
```

## Returns

`return color`

| Value | Type | Description |
|---|---|---|
| color | `Color` | The current foreground color. |
