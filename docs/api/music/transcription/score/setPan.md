# setPan()

Set the stereo position of every note in the score.

## Parameters

Once an object `score` has been created, you can use the following function:

```python
score.setPan(pan)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `pan` | `int or float` | _required_ | The stereo position, from 0.0 (left) through 0.5 (center) to 1.0 (right). |
