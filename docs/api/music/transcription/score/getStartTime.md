# getStartTime()

Return when the score starts.

## Parameters

Once an object `score` has been created, you can use the following function:

```python
score.getStartTime()
```

## Returns

`return startTime`

| Value | Type | Description |
|---|---|---|
| startTime | `int or float` | The start time, in beats, where 0.0 is the start of the piece. |
