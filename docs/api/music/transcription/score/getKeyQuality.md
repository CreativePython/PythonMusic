# getKeyQuality()

Return the score's key quality (major or minor).

## Parameters

Once an object `score` has been created, you can use the following function:

```python
score.getKeyQuality()
```

## Returns

`return keyQuality`

| Value | Type | Description |
|---|---|---|
| keyQuality | `int` | 0 for major, 1 for minor. |
