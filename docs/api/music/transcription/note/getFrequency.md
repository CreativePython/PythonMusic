# getFrequency()

Return the note's pitch as a frequency.

## Parameters

Once an object `note` has been created, you can use the following function:

```python
note.getFrequency()
```

## Returns

`return frequency`

| Value | Type | Description |
|---|---|---|
| frequency | `float` | The pitch as a frequency, in hertz (8.17 to 12600.0). |
