# isRest()

Report whether the note is a rest.

## Parameters

Once an object `note` has been created, you can use the following function:

```python
note.isRest()
```

## Returns

`return noteIsRest`

| Value | Type | Description |
|---|---|---|
| noteIsRest | `bool` | True if the note is a rest, False if it has a pitch. |
