# setPan()

Set the stereo position of every note in the phrase.

## Parameters

Once an object `phrase` has been created, you can use the following function:

```python
phrase.setPan(pan)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `pan` | `int or float` | _required_ | The stereo position, from 0.0 (left) through 0.5 (center) to 1.0 (right). |
